# Test Placement

- Put all tests, browser regression scripts, fixtures, and test-only helpers for this app under `apps/web-ele/test`.
- Use `test/unit` for unit tests and `test/e2e` for browser tests, with feature subdirectories as needed.
- Do not add `.test.*`, `.spec.*`, or `__tests__` under `src`, or create a separate top-level `e2e` directory.
- Do not recreate the removed tests unless a task specifically needs new test coverage.
